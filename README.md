# 低量能一进二模型 · Low-Volume First-to-Second-Board Model

一个给 AI Agent 用的 **A 股两段式选股 Skill**：头天晚上初筛候选，第二天早盘用集合竞价终筛。
产出的名单可以一键导入电脑版同花顺自选股。

> 仅用于个人复盘与规则核对，**不构成任何投资建议**。

## 策略讲什么

**策略1（初筛，交易日 19:00 之后跑）**

1. 除今天以外，往前 **70 个交易日**内出现过**一板涨停（首板）且不连板**，取最近那一波；一次都没启动过的不算。
2. **同题材**今天有 **≥ 2 只同时涨停**（首板、连板都算）。
3. 那波首板的**第二天必须放量分歧**（次日成交量 ≥ 首板日成交量）—— 硬门槛；次日**小溢价（收盘涨 0%~5%）是加分项**。
4. 中间**调整 ≥ 2 个交易日**（调整期一天都不许再涨停），然后**今天再次一板涨停**。

基础过滤：只做主板（沪 `600/601/603/605`、深 `000/001/002/003`），排除 ST / 退市 / 北交所 / 上市不满 60 个交易日的次新。

**策略2（终筛，次日 9:25:15 竞价撮合完）** —— 只在策略1 名单里筛：

1. 竞价价站上涨停价，并从 9:15 扛到 **9:19~9:20**（之后破板往下走可以，一路封到开盘也可以）。
2. 集合竞价量能是**近 30 个交易日最高**（同花顺「飞龙量化 · 竞价量」那根柱子）。
3. **9:25 集合竞价结束价**是近 30 个交易日最高。

不合格的从自选股删掉；采样缺失判不出来的归「待确认」不自动删；**用户自己的票永不动**。

## 装到 Codex / Claude Code

把 `diliangneng-yijiner/` 整个文件夹放进 skills 目录：

```
Codex:       ~/.codex/skills/   (Windows: %USERPROFILE%\.codex\skills\)
Claude Code: ~/.claude/skills/
```

重开一次会话即可。之后跟 Agent 说「跑低量能一进二」或「改策略2 的口径」就会自动用上。

## 数据来源（本地实现用的）

| 数据 | 来源 |
|---|---|
| 涨停池、日K | 同花顺 / 腾讯行情 |
| 题材板块 + 板块涨停家数 | 韭研公社「异动 → 全部异动解析」 |
| 集合竞价量 | 同花顺「飞龙量化 · 竞价量」 |

组合竞价的三方核对口径：飞龙竞价量 = 9:25 那笔集合竞价成交量 = 当日第一根 1 分钟柱。
